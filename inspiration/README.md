# Inspiration Library

## 1. What is this?

The discovery system for visual references: curated *directories* (galleries of many sites), an indexed collection of *individual website references* worth structured study, and the reusable *patterns* extracted from them. It exists because "just browse Awwwards" is not a workflow — an agent needs to find the right kind of reference for the product it is building, read a structured analysis of what makes it work, and translate that into decisions without copying ([contributing.md](contributing.md) rules).

## 2. How to use it

1. **Start from the use case** — [use-case-index.md](use-case-index.md) maps the project types (SaaS landing, e-commerce, editorial, immersive, dashboard…) to the right directories and reference entries.
2. **Search the directories** — [directories.md](directories.md) catalogues the galleries with search craft (what filters actually help on each).
3. **Read reference entries** — [websites/](websites/README.md) holds the structured analyses; the [index](websites/website-index.md) is searchable by industry, style, section, interaction and more.
4. **Extract patterns, not pixels** — [patterns.md](patterns.md) holds the extracted, reusable patterns; the anti-copying rules in [contributing.md](contributing.md) govern how references translate into decisions.
5. **Contribute back** — agents that discover exceptional sites during projects add them via the entry template and index update ([contributing.md](contributing.md)).

## 4. Ground rules

- **Verification discipline.** Every directory URL in this library was checked on 2026-11-25 ([directories.md](directories.md) records statuses; the full log: [../references/frontend-phase-sources.md](../references/frontend-phase-sources.md)). Site entries describe design direction from documented professional knowledge; before relying on a specific detail (exact tech, current section layout), inspect the live site — these are volatile facts.
- **References are studied, not transplanted.** The tasting note is the unit of value: why the design works, what to learn, what to leave. Copying a reference's code, copy or signature effect is prohibited ([contributing.md](contributing.md) §6).
- **Fit beats fashion.** The [use-case index](use-case-index.md) exists because the right reference for a bakery is not the right reference for a fintech dashboard — [../visual-styles/interface-styles.md](../visual-styles/interface-styles.md) §6 governs the fit decision.
- **The library grows.** Every project an agent ships is a chance to add a reference; the contribution workflow keeps the collection deduplicated and indexed.
