# Website Index

## 1. What is it?

The searchable index of the [website reference collection](README.md): every entry cross-listed by industry, visual style, component/section focus, interaction type, typography, colour, motion and project type. Find the entry by any of these facets; the entries themselves carry the full analysis.

## 3. Search notes

- The facets compose: "dark-theme + developer tool + pricing focus" narrows to Linear and Vercel; "pastel + consumer + micro-interactions" narrows to Family.
- The index is updated in the same commit as any new entry ([../contributing.md](../contributing.md) §5) — a reference not indexed here does not exist for routing purposes.
- Entries are dated; before relying on a volatile detail, check the entry's *what to verify live* field ([README.md](README.md) §5).
